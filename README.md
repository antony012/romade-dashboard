# RomaDe Dashboard

Admin Next.js para la API RomaDe.

## Local

```bash
npm install
npm run dev
```

Abre http://localhost:3000

```env
ROMADE_API_URL=http://localhost:3100
```

En Vercel (proyecto del panel), agrega la misma variable en **Settings → Environment Variables** y redeploy:

```env
ROMADE_API_URL=https://latidos-ve.vercel.app
```

Login: `admin` / `admin123` (el admin por defecto de RomaDe).
